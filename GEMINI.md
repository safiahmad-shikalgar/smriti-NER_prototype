Before making changes:
- Read README.md.
- Read docs/ANTIGRAVITY_HANDOFF.md.
- Inspect the relevant source files.
- Preserve existing functionality.
- Preserve offline-first SQLite behavior.
- Preserve Supabase synchronization.
- Preserve accessibility and elderly-friendly UI.
- Run flutter analyze and relevant tests after changes.
